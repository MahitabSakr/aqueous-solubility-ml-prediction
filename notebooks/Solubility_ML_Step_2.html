Reading the data file;

df <- read.csv("df.csv", sep = ",", header = TRUE)

Making the correlation values:

S_mW = round(cor(df$Solubility, df$MolWt, use = "complete.obs"), digits = 3)
S_mLP = round(cor(df$Solubility, df$MolLogP, use = "complete.obs"), digits = 3) 
S_HBA = round(cor(df$Solubility, df$NumHAcceptors, use = "complete.obs"), digits = 3) 
S_HBD = round(cor(df$Solubility, df$NumHDonors, use = "complete.obs"), digits = 3)

Basic scatter plot of solubility and Lipinski specific descriptors:

scatter_MW <- {scatter_plot_1 <- ggplot(df) +
